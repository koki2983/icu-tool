# ICUツール

ICU看護師がベッドサイドで使う、計算・スコア・知識の道具。
ブラウザで開くだけで動き、インストールもログインも不要。

**公開URL： https://koki2983.github.io/icu-tool/**

---

## 1. コンセプト

「ベッドサイドで、計算と確認と学び直しが3タップで終わる」道具。
狙いは計算の時短だけでなく、**知識と判断の標準化**。

- 測り方の標準化：スコアの判定基準と実施手順を選択肢そのものに埋め込み、誰が測っても同じ点になるようにする
- 伝え方の標準化：SBARの型、「先輩に聞かれること」形式で報告の言葉を揃える
- 施設ルールの標準化：自院の希釈・手順を「当院」カテゴリに置き、全員が同じ版を見る

患者情報は一切入力しない設計。入力したデータは端末内だけに保存され、外部に送信されない。

## 3. ファイル構成

**`index.html` の1ファイルのみ。** HTML・CSS・JavaScript・画像（base64）がすべてこの中に入っている。

- ビルド不要。エディタで開いて編集し、ブラウザで開けばそのまま動く
- 外部サーバーへの通信なし（AIに聞く機能は、外部サービスをブラウザで開くだけ）
- データ保存は端末内のみ（localStorage）。メモ・写真・自分の薬剤は端末ごとに独立

### 中の構造（JavaScript内の主な変数）

| 変数 | 中身 |
|---|---|
| `PRESET` | 共通薬剤の希釈。名前・mg・mL・単位・目安（rt/lo/hi）・注意（rn） |
| `KNOW` | 知識メモの本体。`{t:タイトル, fig:図, s:[{h:見出し, b:[本文]}]}` |
| `META` | 各項目のカテゴリ・「まず押さえる」3点・図の配置 |
| `FIG` | 自作のSVG図。文字データなので容量は軽い |
| `PHOTO` / `PHOTOCRED` | 写真・イラスト（base64）と出典 |
| `GLOSS` | 用語集。`[用語, 別名(|区切り), 説明, リンク先項目]` |
| `CATS` / `ORDER` | カテゴリと表示順 |
| `XLINK` | 本文中の自動リンクのキーワード |

## 4. 更新のしかた

### A. Claudeに頼む（現在の運用）

1. Claudeに変更内容を伝える
2. Claudeが `index.html` を編集し、GitHub APIで直接反映
3. 数分で公開URLに反映される

**トークン**
- fine-grained personal access token（icu-toolリポジトリ限定、Contents = Read and write）
- 有効期限：**2026-12-14**。切れたら https://github.com/settings/personal-access-tokens/new から同じ設定で再発行する
- 無期限にはしない。1年程度で区切り、使わなくなったらRevokeする

### B. 手作業でアップロード

1. リポジトリ https://github.com/koki2983/icu-tool を開く
2. 「Add file」→「Upload files」で `index.html` を選ぶ（同名なので上書きされる）
3. 「Commit changes」

### C. Mac（Claude Code など）から

```bash
git clone https://github.com/koki2983/icu-tool.git
cd icu-tool
# index.html を編集
git add index.html && git commit -m "変更内容" && git push
```

## 5. 編集のときの約束ごと

### 医療情報

- 数値は一般的な目安として書き、**施設基準・医師の指示が優先**であることを明記する
- 自院だけのルールは「当院」カテゴリに置くか、本文に「当院は〜」と書いて出所を分かるようにする
- ガイドラインを引くときは年号を入れる（例：J-SSCG 2024）
- 書籍・資料の文章や図をそのまま写さない。内容は自分の言葉で書き直し、図は描き起こす

### 画像

- 公開ライセンス（CC0・パブリックドメイン・CC BY・CC BY-SA）のものだけを使う
- 作者名・ライセンス・元画像へのリンクを画像の下に必ず表示する（`PHOTOCRED`）
- 患者の画像を使う場合は、施設の規定と同意の確認が必要。氏名・ID・日付は必ず外す

### 表記

- 数値には必ず単位をつける（mEq/L、mmHg、mg/dL、γ など）
- 略語は初出で日本語を添える。馴染みのない言葉（burden など）は言い換えを併記する
- 薬剤は一般名と商品名を併記する
- 「ペーシングフェラー」「センシングフェラー」のように、現場で使う言い方に合わせる

### 図（SVG）

- 文字がviewBoxの外に出ると切れる。編集したら必ずスマホ幅（390px）で表示を確認する
- 1行あたりの目安：font-size 9 で全角約30文字

## 6. 困ったとき

| 症状 | 対処 |
|---|---|
| 更新したのに変わらない | URLの末尾に `?v=数字` を付けて開く。ホーム画面アプリは一度完全に閉じる |
| 画面が真っ白 | JavaScriptの構文エラー。GitHubの「History」から前のバージョンに戻す |
| 前の状態に戻したい | リポジトリ → History → 戻したいコミット → 「Browse files」→ そのバージョンのindex.htmlをダウンロードして再アップロード |
| 重い・遅い | 画像の圧縮率を上げる、または大きい画像の幅を縮める。目安は6〜7MBを超えたら |
| メモが消えた | 端末内保存のため、ブラウザのデータ削除で消える。ホーム画面に追加した状態での使用を周知する |
